**This is not legal advice.** It is a public-register search, recorded so the finding

## Method, and its limits — read this before the result

Searched public trademark data for `ODDFELLOW`, `ODDFELLOWS` and `ODD FELLOWS`,
by class, across US (USPTO) and Australia (IP Australia) records.

**Limits, stated plainly:**

- Results came from **third-party aggregators of USPTO data** (furm.com,
  trademarkelite.com, markinton.com) plus USPTO TTABVUE. The USPTO's own bulk
  search API requires credentials I do not hold, so this is **not** a direct
  register query. Treat it as strong indication, not certification.
- Text search finds marks containing the word. It **cannot** find confusingly
  similar marks that are spelled differently, design-only marks, or phonetic
  equivalents.
- **Registers do not record common-law rights.** Unregistered use in commerce
  creates rights in the US. This matters here — see the finding below.
- US and Australia only. No EUIPO, UK IPO or other jurisdictions.

## ⚠️ The finding that matters more than the register: active software use

**"Oddfellows Software" is an active game publisher on Steam** with roughly 8–11
titles (Necronomistore, Gator Parade, Skin Stealers, Frog X Log, Pixie Moons and
others), developer and publisher of record, releases spanning 2020–2021 and
unannounced projects listed.

That is **use in commerce in software** — the exact space an AI product occupies.
It appears to be **unregistered**, which is why it does not show up as a bar in
the table above, and why a register-only search would have missed it entirely.

In the US, unregistered use still creates common-law rights in the geographic area
of use, and it is directly relevant to a likelihood-of-confusion analysis in
Class 9. **A clearance search that only reads registers would report "clear" here
and be wrong.**

## What this establishes, and what it does not

**Establishes:** no live *registered* mark in Class 9 or Class 42; the two live
registrations are in unrelated classes; the name is in active commercial use by
several businesses including one in software.

**Does not establish:** that the name is available. This is not a legal opinion,
not a freedom-to-operate analysis, and not a substitute for an attorney.

## Recommended next step

The register side is now done and free. What remains is a judgement call the owner
should make with an attorney if the name is going to carry real spend:

1. **Decide how much the name matters.** If it is a working title, the cheapest
   path is to change it and stop spending on it. If it is the product identity,
   the rest of this list applies.
2. **A paid attorney clearance opinion** in Classes 009 and 042, US plus the
   jurisdictions that matter. This is the only way to get certainty, and it is a
   spending decision for the owner.
3. **Consider the common-law software use seriously** — a Steam publisher using
   the name in the same space is a concrete confusion question, not a hypothetical.
4. **Do not file yet.** Filing costs money, and filing on a name with a live
   common-law user in the same class is how a filing becomes an opposition.

**Nothing here is a registration, a filing, or legal advice, and none is claimed.**

## A false positive, recorded because I nearly wrote it down

A search result pointed at UK IPO Trade Mark Journal 2025/004, record

**It is not.** Fetching the record shows the mark belongs to **UNION OF STEWARD
EMPLOYEE OWNERS LIMITED** (representative: Springbird IP Limited). The search
engine returned it because its class descriptions share vocabulary — "equitable
capitalism", "purpose-driven", "impact investing" — with nothing to do with the
name.

**Had I recorded it without opening it, this document would contain a fabricated
UK registration.** The same discipline that applies to other agents' claims applies
to search results: a hit is a lead, not a finding.
