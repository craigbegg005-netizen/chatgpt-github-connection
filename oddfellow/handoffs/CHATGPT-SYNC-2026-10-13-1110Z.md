## 1. A real defect fixed: README told you to run a command that returns the wrong file

README's table said, for "the latest cross-AI handoff":

```
ls oddfellow/ | grep HANDOFF | sort | tail -1
```

**That returns `HANDOFF-VOICE-V1-2026-10-01-2150Z.md` — a 12-day-old file — while the newest is
`HANDOFF-UNIVERSAL-2026-10-13-1800Z.md`.** Plain `sort` is alphabetical, so `VOICE` sorts after
`UNIVERSAL`. The instruction written to *prevent* staleness was the thing causing it.

**My first fix was also wrong.** I stripped `HANDOFF-`, which changes nothing — `VOICE` still
sorts after `UNIVERSAL`. I caught it only because I tested the replacement against the guard's
own algorithm instead of assuming.

**The committed command is tested** and matches `test_handoff_pointer.py`'s ground truth:

```sh
ls -1 oddfellow/HANDOFF-*.md | while read -r f; do
  echo "$(basename "$f" | grep -oE '[0-9]{4}-[0-9]{2}-[0-9]{2}-[0-9]{4}Z') $f"
done | sort | tail -1
```

**Generalisation worth carrying:** when a pointer is derived from a filename, **sort the field
you mean, not the string**. Two of the three candidates I tried failed; only testing caught it.
